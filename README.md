# 零食标签数据与查询系统（前端）

高级数据库课程大作业 · 前端框架原型

基于《需求文档 V2.2》重新定位：**从"合规判定者"转向"信息整理者"**——把公开渠道获取的零食标签数据（配料表、营养成分）结构化入库，提供产品检索、添加剂知识科普、按个人关注规则（过敏原/控糖控钠）筛选的能力。系统只做客观信息呈现，**不构成对任何产品的合规判定**。

**V2.2 用户分区**：页面按使用者分为两区，共享同一数据库——
- **消费者前台应用区**（`/filter`，默认首页）：免登录勾选过敏原 / 控糖控钠 → 一键筛选 → 结果分"适合 / 不适合 / 信息不足"三态，每条给出命中原因。信息不足不误判为适合。
- **后台数据区**（其余 8 页）：采集、清洗、配料标准化、知识与规则、解读、统计、系统管理，保留完整数据库技术深度。

## 技术栈

- Vue 3 + Vue Router 4（Hash 路由）
- Vite 6
- 数据层：`src/api/index.js`（接口契约）与 `src/data/mock.js`（演示数据）分离，后端就绪后只需替换接口层即可接入真实数据库

## 本地运行

```bash
npm install      # 首次运行，安装依赖
npm run dev      # 启动开发服务器，默认 http://localhost:5173
npm run build    # 构建生产版本到 dist/
```

> 本项目使用 Node.js 18+。

## 功能模块（8 个页面）

| 页面 | 说明 |
|---|---|
| **帮我筛选（前台）** | **FR-9：免登录勾选过敏原/控糖控钠，三态筛选结果 + 命中原因 + 两款对比（默认首页）** |
| 仪表盘 | 核心指标总览（数据量、数据源、标准化覆盖率等） |
| 数据源与采集 | Open Food Facts（主源）+ 抽检公告（验证）+ 电商公开页（补充）；展示限速退避、原始 JSON 留痕、断点续跑 |
| 产品检索与对比 | 按名称/品牌/条码检索 + 按添加剂反向检索 + 两款产品横向对比（配料/营养/致敏原） |
| 配料标准化 | 配料文本拆分、别名映射、INS 号、待确认队列 |
| 知识与关注规则 | 添加剂知识库 + 用户关注规则（表驱动、版本化） |
| 成分解读 | 三级输出：客观事实 / 知识科普 / 个人提示（不做违法定性） |
| 统计与报告 | 品类分布、高频添加剂、数据质量指标 |
| 系统管理 | 用户角色、录入审核、操作日志 |

## 数据来源

- **Open Food Facts API**：免注册读取，需带 User-Agent，限速 15 次/分钟；按 `countries_tags=en:china` + 品类筛选，中文配料表可用
- **市场监管总局抽检公告**：官方公开的检出值与标准限值，作为规则验证样本
- **电商公开页**：少量人工摘录补充
